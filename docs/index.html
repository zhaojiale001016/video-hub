01

一条流水线，七个显式环节

每个环节都是独立模块，输入输出落进 sqlite 队列。哪一环出问题，状态就停在哪一环——不吞错，不黑盒。

01

轮询发现cli.py poll

按 sources.yaml 轮询频道/搜索源，每源封顶 per_source_poll_cap 条。每次结果写进源健康档案 source_health.json，哪个源报错一眼看出。

02

撞稿预检precheck

下载前先拿标题搜 B站：相似度 ≥0.72 拦截，≥0.85 直接跳过并清文件，自动排除自己已发的稿。两道阈值都可在设置里调。

03

下载入库yt-dlp + archive

清晰度上限、代理、每日额度 daily_download_limit、磁盘水位 min_free_gb 都是守卫。下载记录进 archive，重下永不重复拉流。

04

字幕：生肉 → 熟肉whisper

按内容线配策略：always / auto / subs_only / never。auto 模式先试转前 3 分钟、VAD 过滤幻觉、≥60字/分钟才判定有解说。字号随分辨率自适应，烧录或外挂可选。

05

中文元数据LLM

本地 kscc 或任意 OpenAI 兼容后端，按内容线风格生成：标题 ≤80 字、标签 ≤12 个、简介 ≤1500 字，并给出 B站分区建议。随时「重生成」。

06

人工审核管理台

FastAPI 单页管理台：五态队列、封面预览、抽屉里改标题/简介/标签、勾发布平台、设定时。published 之后锁死只读——不与线上稿件脱节。

07

逐平台投递publish

B站走 biliup-rs（分区/活动/版权/定时），其余 13 平台走浏览器自动化。每平台独立记账 extra_pub，失败不阻断；补投自动跳过已成功平台。

GUARD 01
DB 唯一键

UNIQUE(platform, source_id)——同一视频只入队一次，频道源和搜索源命中也合并

GUARD 02
下载 archive

yt-dlp download_archive 兜底，状态重置也不重下

GUARD 03
published 免入

已发布条目永远不再进入下载/发布流程

GUARD 04
撞稿预检

相似度 ≥72% 拦截，防搬别人搬过的稿

GUARD 05
同名拦截

与已发布稿件同名的直接拒绝

02

一稿多投，平台之间互不相欠

每个平台是平等的投递目标：单稿勾选 pub_platforms（空=启用平台全发，[]=拒发）。投递结果逐平台记进 extra_pub——这是"补投不重复"的全部依据。

03

挂上常驻，它自己上班

调度器每 tick 重读配置，设置面板里改的任何值即时生效、免重启。你只负责审核，剩下的交给它。

Scheduler

自动轮询 + 连带下载

auto_poll_interval_min 分钟一轮；auto_download_after_poll 开了就连带下载处理。auto_workdays_only 让周末整 tick 休息（手动按钮不受影响）。

tick → poll → backup_db → prune_stale → verify → (optional) download
Quota

每日额度

daily_download_limit / daily_upload_limit 用完自动停，明天继续。卡片手动下载不占额度。

Schedule

错峰定时

publish_slots 档位自动分配，间隔下限 publish_slot_gap_h；支持定时的平台同步对齐。

Hygiene

积压老化

stale_days 天没动过的待下载条目自动跳过（可恢复），队列保持新鲜。

Reconcile

启动调和

进程死在任务中途的残留：启动时清孤儿文件、清卡死进度登记、报告断档条目。

Verify

存活巡检

cli.py verify 复核已发稿件，下架/退回标出并桌面通知。

Backup

每日快照

sqlite 队列每天一份进 data/backups/，保留最近 7 份；任务历史落盘 jobs.log。

Doctor

一体检三命令

cli.py doctor 查登录态/活动/队列/额度；cli.py reconcile 手动调和；cli.py jobs 看跨重启的任务历史。

$ cli.py doctor  →  cookie ✓ · 登录态 ✓ · 今日已投 2/5 · 磁盘 41G

不想点鼠标，就把流水线交给 agent

四种接入方式，同一组 hub_* 工具：查队列 / 改元数据 / 发布 / 补投 / 加源 / 追任务。纯附属能力——不装，Web 管理台照常工作。

DSH 原生插件推荐

20 个 hub_* 工具进 DeepSeek Harness 原生工具系统；插件市场一键安装，发新版提示升级。

MCP Server

零协议依赖 stdio server（只需 httpx）。Claude Code / Cursor / Devin / Windsurf，配一段 JSON 即用。

Agent Skill

不想配 MCP：软链 SKILL.md 进 skills 目录，教 agent 用 REST/CLI 驱动，含语义红线。

裸 API / CLI

任何能发 HTTP 的 agent：/openapi.json 自举；或直接调 CLI。最底层兜底。

05

十条命令以内，跑起来

Python ≥3.11 + ffmpeg。biliup 二进制在 README 里下。sau 引擎可选——只用 B站的话整段跳过。

bash
# 环境
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# sau 投递引擎(13个浏览器自动化平台; 只用B站可跳过)
cd vendor/sau && python3 -m venv .venv && .venv/bin/pip install -e . \
  && .venv/bin/patchright install chromium && cd ../..

# 配置（首启自动从 example 复制）
cp config/sources.example.yaml config/sources.yaml
#   → sources 里配你的订阅源，line 起任意名字

# 登录: B站 + 任意 sau 平台(扫码弹浏览器)
.venv/bin/python3 cli.py login                # B站
.venv/bin/python3 cli.py login-extra douyin   # 抖音/快手kuaishou/视频号tencent...

# 启动 → http://127.0.0.1:8600 (设置面板勾选启用平台)
.venv/bin/python3 cli.py serve
.venv/bin/python3 cli.py doctor               # 体检

# ── 常驻托管 ──
# macOS: deploy/com.videohub.pipeline.plist.example → launchd
# Linux: deploy/video-hub.service.example           → systemd
本地私有 · 管理台无鉴权，只监听 127.0.0.1（远端绑定直接拒绝启动）；cookie / 队列 / 代理账密全部留在 gitignore 的 data/ 里，API 回显自动打码。
