Pipeline

五步流水线，全自动跑通

从订阅源发现到三平台投递，每一段都可单独手动干预。

01

订阅源轮询

YouTube 频道/关键词搜索，定时拉新；撞稿预检相似 ≥72% 自动拦截

02

下载 + 字幕

yt-dlp 下载，whisper 探测语音→转写→翻译→烧入画面；按源配策略

03

LLM 元数据

kscc/OpenAI 兼容接口生成中文标题、简介、标签，B站分区自动匹配

04

管理台审核

封面预览、标题编辑、平台勾选、错峰定时、活动匹配，本地 127.0.0.1

05

三平台发布

B站(biliup)+快手+视频号(sau) 独立投递互不阻断，逐平台留痕；部分成功可补投

Features

为「持续搬运」设计的机制

🛡

五层防重复

DB 唯一键 + yt-dlp archive + 已发布免重入 + 撞稿预检 + 同名拦截——同一视频绝不会下载两次、重投两次。

⧉

三平台平等

B站/快手/视频号无主次之分，任意勾选组合；只发快手时 B站域流程（撞检/活动/biliup）完全跳过。

↻

重试去重

逐平台记录投递结果；已发布稿件可「补投失败平台」，已成功的平台绝不重复投稿产生双稿。

⚙

配置全前端可控

限额/调度/字幕/LLM/屏蔽词/平台开关都在设置面板热更新，sources.yaml 与 overrides.json 分层。

⏱

错峰定时

稿件自动排到 ≥4h 间隔的预设档位，跨次分配不撞档；每日下载/上传限额养号防风控。

字

生肉→熟肉

whisper VAD 探测是否有解说，按源策略选 官方字幕翻译/whisper转写/跳过，字幕样式随分辨率自适应。

🗓

仅工作日自动

调度器每 tick 重读配置，周末自动停摆，手动按钮不受影响；launchd 常驻崩溃自愈。

🗑

积压老化

发现超过 14 天未下载自动转 skipped（可恢复），队列不无限堆积；全部勾选平台成功才自动删文件，部分成功保留供补投。

🔒

本地私有

cookie/队列/下载全在 gitignore 的 data/；管理台仅监听 127.0.0.1；API 回显自动给代理账密打码。

Quickstart

四步跑起来

1

装环境

Python ≥3.11 + ffmpeg；创建 venv 装 requirements

2

备配置

复制 sources.example.yaml，或首启自动创建

3

登录

三个平台分别扫码，cookie 存本地 data/

4

启动

cli.py serve 起管理台，可选 launchd 常驻

bash · 需要 ffmpeg，biliup 二进制见 README复制
# 1. 环境
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# 2. 配置（首启缺省自动从 example 复制）
cp config/sources.example.yaml config/sources.yaml

# 3. 登录（扫码）
.venv/bin/python3 cli.py login      # B站
.venv/bin/python3 cli.py login-ks   # 快手
.venv/bin/python3 cli.py login-sph  # 视频号

# 4. 跑起来
.venv/bin/python3 cli.py serve --port 8600
# → http://127.0.0.1:8600
