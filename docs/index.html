Capabilities

工具能力，不设边界

⧉

平台可扩展

B站走 biliup-rs；快手/视频号/抖音/小红书等 13 个平台走 social-auto-upload。设置面板勾选启用，login-extra 扫码即用，封面/定时参数按各平台能力自动适配。

◈

内容线自定义

line 任意小写 slug——音乐/解压/游戏/烹饪随你定。字幕策略、活动匹配、LLM 风格按同名 key 联动，徽标颜色自动分配。

🛡

五层防重复

DB 唯一键、下载 archive、已发布免重入、撞稿预检（阈值可调）、同名拦截——同稿绝不二次处理。

字

生肉→熟肉

官方字幕翻译 / whisper 转写 / 直接跳过，按内容线配策略；字号随分辨率自适应，可烧录可外挂。

⚙

配置全热更新

限额/调度/阈值/字幕/LLM/屏蔽词/平台开关全部设置面板即改即生效，yaml 底包 + overrides 分层。

🔒

本地私有

无鉴权但只监听 127.0.0.1（远端绑定直接拒绝启动）；cookie/数据全在 gitignore 的 data/；sqlite 每日备份留 7 份。

Quickstart

跑起来

bash · Python ≥3.11 + ffmpeg · biliup 下载见 README复制
# 环境
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# sau 投递引擎(13个浏览器自动化平台; 只用B站可跳过)
cd vendor/sau && python3 -m venv .venv && .venv/bin/pip install -e . \
  && .venv/bin/patchright install chromium && cd ../..

# 配置（首启自动从 example 复制）
cp config/sources.example.yaml config/sources.yaml
#   → sources 里配你的订阅源，line 起任意名字

# 登录: B站 + 任意 sau 平台(扫码弹浏览器)
.venv/bin/python3 cli.py login                # B站
.venv/bin/python3 cli.py login-extra douyin   # 抖音/快手kuaishou/视频号tencent...

# 启动 → http://127.0.0.1:8600 (设置面板勾选启用平台)
.venv/bin/python3 cli.py serve

# ── 接 AI agent(四选一) ──
# DSH 原生插件:
dsh plugin --profile desktop add ./plugins/dsh-video-hub
# MCP:        cli.py mcp   → 配进 Claude/Cursor/Devin
# Skill:      软链 skills/video-hub → .claude/.codex/.devin skills 目录
# 裸 API:     http://127.0.0.1:8600/docs
